Respaldo de datos

Descarga una copia de todos los datos de HogarFix (clientes, técnicos, servicios, pagos, boletas, chat, comprobantes…). Hazlo cada semana y guárdalo fuera de Railway y de Aiven.

Contraseña incorrecta.

Puede tardar unos segundos. Cada descarga queda registrada en Actividad.

Cuidados

  • El archivo tiene datos personales y contraseñas cifradas: no lo envíes por WhatsApp ni lo subas a lugares públicos.
  • Guárdalo en tu computadora y en un segundo lugar privado (por ejemplo tu Google Drive personal).
  • Se guardan los datos. Las tablas las vuelve a crear la aplicación sola al arrancar.

Cómo restaurarlo

  1. Arranca la aplicación una vez con la base de datos nueva y vacía (así se crean las tablas).
  2. Descomprime el .zip y ejecuta el archivo respaldo-hogarfix.sql contra esa base de datos (por ejemplo con MySQL Workbench o mysql).
  3. Si salen errores de filas repetidas, es porque la base ya tenía datos: vacía las tablas primero.
